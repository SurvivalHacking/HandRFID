
# HandRFID
Portable RFID tag reader-writer for filaments / Lettore-Scrittore di TAG RFID per filamenti

## 📘 Description / Descrizione

A small, portable device that allows you to quickly write RFID tags to label your spools. Compatible with QIDI and ANYCUBIC systems, but can be updated to support other standards as they become more widespread. / Un piccolo dispositivo portatile, che consente la scrittura rapida dei TAG RFID per battezzare le vostre bobine. Compatibile con sistemi QIDI e ANYCUBIC, ma aggiornabile per altri standard che prenderanno piede.

* Battery-powered / Funzionante a batterie
* Touchscreen / Touch Screen
* Material database / Database materiali
* Manufacturer database / Database costruttori
* Web-configurable / Configurabile via WEB
* Easy to implement / Facile da realizzare
